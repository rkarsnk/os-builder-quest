# os-builder-quest

教育用OS「xv6」(RISC-V版)を題材に、ゲーム感覚でOSの内部構造を学べるWebアプリ。

## コンセプト

- xv6というOSそのものを「一つの国家」に見立てた**国家建築シミュレーション**の世界観
- 進行役は**女王**、プレイヤーは**宰相**。女王が提示する国家運営上の課題に優先順位をつけ、その提案に基づいて謎解き(実装課題)を進める
- 学習開始時点のkernelは何も実装されていないビジーループのみの状態(荒野)からスタートし、ステージクリアごとに国が発展していく
- 各ステージは読解クイズ→穴埋め→ブロック実装→関数実装→バグハント→自由拡張課題、の6段階で難易度が上がる
